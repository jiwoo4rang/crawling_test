# 🏛️ 충청남도 의회 자유게시판 크롤링 스크립트

이 프로젝트는 충청남도 의회 홈페이지의 자유게시판(5분 발언 게시판)을 자동으로 크롤링하여, 의원들의 발언 내용을 수집하고 CSV 파일로 저장하는 Python 스크립트입니다. 공공 데이터를 효율적으로 수집하고, 텍스트 데이터를 정제하여 재사용 가능한 형태로 저장하는 데 목적이 있습니다. 📊

## 🔍 주요 기능

- ✅ **자동 크롤링**: Playwright를 사용해 브라우저 자동화로 동적 웹페이지를 안정적으로 크롤링합니다.
- ✅ **데이터 추출**: 게시글 목록에서 링크를 추출하고, 상세 페이지에서 제목, 의원 이름, 발언 내용 등을 파싱합니다.
- ✅ **텍스트 정제**: 불필요한 HTML 태그, 공백, 중복 줄바꿈을 제거하고, 단락을 깔끔하게 정리합니다 (예: 'SNS 공유' 같은 메뉴 텍스트 필터링). 🧹
- ✅ **중복 방지 및 안정성**: 기존 파일 확인으로 중복 수집 방지, 재시도 로직으로 에러 페이지(502 Bad Gateway 등) 대응, 타임아웃 처리. 🛡️
- ✅ **역순 수집**: 마지막 페이지부터 시작해 최신 데이터를 우선적으로 가져옵니다. 🔄
- ✅ **CSV 저장**: 각 게시글을 개별 CSV 파일로 저장 (파일명: 게시물번호_제목.csv), 데이터 분석이나 검색에 용이. 💾

## 📋 요구사항

- Python 3.8 이상 🐍
- Playwright 라이브러리
- Chrome 브라우저 (Playwright가 자동 설치) 🌐

## ⚙️ 설치 방법

1. Python 환경을 설정하세요.
2. 필요한 라이브러리를 설치하세요:
   ```
   pip install playwright
   playwright install
   ```

## 🚀 사용법

스크립트를 실행하면 자동으로 크롤링이 시작됩니다:

```
python crawl_chungnam_free_speeches.py
```

- `HEADLESS = True`로 설정 시 브라우저 창 없이 백그라운드에서 실행됩니다. 👻
- `TEST_LIMIT`을 설정해 테스트용으로 제한된 수의 게시글만 수집할 수 있습니다 (기본값: None, 전체 수집). 🧪
- 실행 중 기존 파일을 만나면 중지됩니다 (중복 방지). ⏹️

## 📁 출력

- 출력 폴더: `output_chungnam_free/posts_csv/` 📂
- 각 CSV 파일에는 다음 필드가 포함됩니다:
  - 제목
  - 차수
  - 회의일
  - 의원
  - 내용

예시 파일: `1_김태흠 도정 지역 간, 산업 간 균형발전 정책 보완 필요.csv` 📄

## 🔧 문제 해결

- 에러 페이지가 발생하면 자동 재시도합니다 (최대 2회). 🔄
- 네트워크 불안정 시 `RETRY_WAIT_MS`를 조정하세요. ⏱️
- 크롤링 속도를 조절하기 위해 `slow_mo` 파라미터를 사용합니다. 🐢
