# 🏛️ 충청남도 의회 자유게시판 크롤러

충청남도 의회 홈페이지의 자유게시판(5분 발언 게시판) 글을 수집해 게시글별 CSV 파일로 저장하는 Python 스크립트입니다.

Playwright를 사용해 동적 페이지를 순회하고, 각 상세 페이지에서 제목, 회차 정보, 회의일, 의원명, 발언 내용을 추출합니다. 수집한 텍스트는 후처리를 거쳐 분석이나 검색에 다시 활용하기 쉬운 형태로 저장됩니다. 📊

## ✨ 주요 기능

- 자유게시판 목록 페이지를 순회하며 상세 글 링크 자동 수집
- 게시글별 제목, 차수, 회의일, 의원명, 본문 추출
- 메뉴 문구, 만족도 조사 문구, 불필요한 공백과 줄바꿈 제거
- 에러 페이지 대응을 위한 재시도 로직 포함
- 기존에 저장된 게시물 번호를 기준으로 중복 수집 방지
- 게시글별 개별 CSV 파일 저장

## 🛠️ 사용 기술

- Python 3.8+
- Playwright

## 📁 프로젝트 구조

```text
crawling/
├─ crawl_chungnam_free_speeches.py
├─ README.md
└─ output_chungnam_free/
   └─ posts_csv/
```

## ⚙️ 설치 방법

1. Python 3.8 이상이 설치되어 있는지 확인합니다.
2. 필요한 패키지를 설치합니다.

```bash
pip install playwright
playwright install
```

## ▶️ 실행 방법

```bash
python crawl_chungnam_free_speeches.py
```

실행하면 `output_chungnam_free/posts_csv/` 아래에 게시글별 CSV 파일이 생성됩니다. 💾

## 🧾 저장 형식

각 CSV 파일은 다음 필드를 포함합니다.

- `제목`
- `차수`
- `회의일`
- `의원`
- `내용`

파일명 형식은 아래와 같습니다.

```text
게시물번호_제목.csv
```

예시:

```text
1_김태흠 도정 지역 간, 산업 간 균형발전 정책 보완 필요.csv
```

## 🔧 주요 설정값

스크립트 상단에서 아래 값을 조정할 수 있습니다.

- `HEADLESS`: `True`면 브라우저 창 없이 실행
- `TIMEOUT`: 페이지 로딩 타임아웃
- `TEST_LIMIT`: 테스트용 수집 개수 제한, `None`이면 전체 수집
- `RETRY_COUNT`: 상세 페이지 재시도 횟수
- `RETRY_WAIT_MS`: 재시도 전 대기 시간(ms)

## 🔄 동작 방식

1. 목록 첫 페이지에서 전체 게시물 수를 확인합니다.
2. 마지막 페이지부터 역순으로 이동하며 게시글 링크를 수집합니다.
3. 각 상세 페이지에 접속해 필요한 정보를 추출합니다.
4. 텍스트를 정제한 뒤 CSV로 저장합니다.
5. 이미 저장된 게시물 번호를 만나면 수집을 종료합니다.

최신 게시글부터 빠르게 이어서 수집하려는 흐름에 맞춰 구성되어 있습니다.

## ⚠️ 주의사항

- 사이트 구조가 바뀌면 선택자나 정규식 수정이 필요할 수 있습니다.
- 실행 환경에 따라 Chrome 설치 상태나 Playwright 설정이 영향을 줄 수 있습니다.
- 현재 출력 결과물(`output_chungnam_free/posts_csv/`)도 저장소에 포함되어 있습니다.
